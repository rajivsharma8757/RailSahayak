# RailSahayak — Feature and Integration Matrix

This document provides a rigorous, transparent technical assessment of the implementation status, integration dependencies, and boundary guarantees across all features of **RailSahayak**.

---

## 1. System Scope and Operational Boundaries

> [!IMPORTANT]
> **Strict Operational Boundaries:**
> - **Smart Train Finder:** Uses sample route prototypes only. It is **not** connected to live CRIS/NTES seat inventory and does **not** provide live seat counts or live train delays.
> - **PNR Guide:** Provides procedural explanation of Indian Railways PNR status codes (CNF, RAC, WL, etc.) and charting rules. It does **not** perform live database lookups against the CRIS Passenger Reservation System (PRS).
> - **Payment Help:** Provides advisory troubleshooting checklists and settlement timeline guidance based on Indian Railways and banking standards. It does **not** initiate, process, query, or refund banking transactions.
> - **Complaint Tracking:** Persists support tickets in RailSahayak's local PostgreSQL database. It does **not** auto-escalate to official Ministry of Railways systems (such as RailMadad) without official API authorization and technical integration.
> - **Booking & Ticketing:** Actual ticket booking, quota allocation (Tatkal/Premium Tatkal), and direct financial processing are **not** implemented in RailSahayak. All bookings must be completed on official Indian Railways portals ([irctc.co.in](https://www.irctc.co.in/)).
