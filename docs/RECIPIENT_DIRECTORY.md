## 1. Executive Summary & Purpose of Directory

This directory compiles primary, verified institutional contacts across eight distinct public organizations in Indian Railways governance, national innovation bodies, and academic incubators. It provides a structured, professional framework for soliciting:
1. **Technical feedback & architectural critique** from railway software systems architects (CRIS / IRCTC).
2. **Procedural guidance & regulatory alignment** with passenger rules and circulars (Railway Board / Commercial Directorate).
3. **Innovation challenges & pilot opportunities** under dedicated railway policies (RDSO "Startups for Railways").
4. **Incubation, mentorship, and seed grant support** for a solo student developer with limited financial resources (Startup India, Atal Innovation Mission, MMDU Mullana, and Startup Haryana).

### Strict Outreach Protocols
- **No Mass Mailing / No Automated Spam:** Each communication is sent individually, tailored specifically to the recipient's institutional mandate.
- **Sensitive, Professional Framing:** Clearly discloses student status, resource limitations, and prototype boundaries without exaggeration or despair.
- **Zero Official Endorsement Claims:** Explicitly confirms that RailSahayak is an independent research prototype with no live production PRS or banking integrations.
- **Safe Evaluation:** Public reviewers access the passenger role via demo credentials; administrative credentials are provided strictly upon request.
